# Adversarial review: network-sync-and-control.md (round 1)

Verdict: not safe to build the kill switch until 1-4 are fixed. Decision from the
main session: adopt every proposed fix below; no item is escalated.

1. BLOCKER §0/§1: any model turn or contact can fire/lift/revoke. `_require_human_network_context` (relay_agent.py:372-379) only checks relay-turn contextvars inside the owner; an agent's terminal tool can run `kollab --hub halt --revoke <device>` as a fresh CLI (Trust All default, manager.py:116), and can delete `halt.json`. Fix: terminal tool sets `KOLLAB_TOOL_SHELL=1`; halt/resume/revoke refuse with it set or without a TTY (except the TUI key / web panel action); add to HIGH patterns; state that same-user code can read the device key.
2. BLOCKER §1 --revoke: revocation already network-wide on one member's word (`accept_membership`, relay_client.py:514-516), sticky until re-join; a compromised device can revoke the primary and every honest device first = permanent takeover. Fix: a device never revokes its own primary or admitter on a peer's word; revocation needs the primary's signature or a second agreeing device.
3. BLOCKER §1 epochs: newest-epoch-wins across issuers + 10 min future skew lets a compromised device lock honest issuers out 10 min, and a pre-signed resume outranks a later halt --revoke. Fix: apply revoke lists whichever order wins; per-issuer counters, not cross-issuer clocks; a resume names the hash of the halt it lifts; halt beats resume on ties; skew ~60 s.
4. BLOCKER §1 steps 3-4: halted machine goes deaf (service start exits 0 vs owner still starts; after reboot nothing holds the link). The owner is itself an agent with presence and would be stopped; one network daemon per folder, not one owner. Fix: halted owner = model-less listener that a service start runs instead of exiting; exclude its pid; pick exactly one per machine.
5. MAJOR resume: presence has no argv/start mode/loadout/--as/KOLLAB_LAUNCH_BRIEF (kollabor_agent/runtime.py:624). Fix: write a launch record at start, or only auto-restart service units and list the rest for the human.
6. MAJOR halt coverage misses: -p pipe, --no-daemon, KOLLAB_NO_HUB (no presence), voice service/LiveKit worker responder, engine POST /sessions spawns, /terminal tmux sessions, nohup'd tool children (codex/claude CLIs), other OS users' services; guard_model/guard_tool only in owner. Fix: kill each agent's process group, boot check in every entry point incl. pipe and ACP, stop terminal-plugin tmux sessions.
7. MAJOR wrong "today" claim: member lists are not resent every 10 s; `tick()` skips same digest (network_members.py:176-207). Fix: include halt hash in the digest; correct the claim.
8. MAJOR §3 uncheck: apply deletes previously managed keys missing from the bundle (config_sync.py:1129-1131); re-check gets nothing until the primary changes. Fix: rewrite the managed record in the owner under the apply lock before filtering; refused groups out of `previous`; re-check sends a resync request.
9. MAJOR §3 denylist: unlisted plugins.hub keys would sync (strict_local_unknown_senders plugin.py:10084, presence, user_name, coordinator_auto_breakthrough, loop_detection_threshold, wait_cooldown_seconds, feed_max_age, extra_task_assignment_markers, kollabor.updates.release_notes); kollabor.voice.serve missing from local list. Fix: allowlists for hub and updates groups; add kollabor.voice.serve as local.
10. MAJOR §3 defaults: sync_take.* default true silently widens existing secondaries on upgrade (guarded by config_sync.py:58-61 comment). Fix: devices joined before this release default permissions/voice/updates to not taken.
11. MAJOR §3: refusal only holds if agents/skills/mcp also refused; synced prompts run raw `<trender>cmd</trender>` (prompt_renderer.py:970-990), MCP runs code, either can flip sync_take back. Fix: say so; read-only example refuses agents/skills/mcp, or neutralize raw trender in synced prompts on receipt.
12. MAJOR §4: asks carry full command + 10-line content_preview (manager.py:986-996) over an open hub channel written to vault streams. Fix: deliver to the coordinator only, through redact_secrets, drop content_preview.
13. MAJOR §4: answers forgeable (require_auth False, plugin.py:786; coordinator = flock winner, coordinator.py:43; any shell can `kollab --hub msg` as it); a coordinator allow on a Stop-parked card would run what the human stopped. Fix: answers only over authenticated socket RPC checked against the flock holder pid; parked asks never take a coordinator answer.
14. MAJOR §4: HIGH is regex-only; bash -c/env wrappers slip (risk_assessor.py:105-125). Fix: coordinator may only allow a fixed list (reuse `_voice_may_run`); everything else to the human.
15. MAJOR §5: remote/api STT transcripts count as the live human (/voice in YES_SOURCES) so a returned "yes" approves calls; a compromised member or primary-pushed stt.source gets every mic. Fix: source fields machine-local, never synced; remote transcripts tagged, never YES_SOURCES; bind device by key.
16. MAJOR UI parity: connect_altview.py does not import kollabor/panels/connect.py; panel dropdowns fire their own action (connect.py:196-199), no form state; read-only panel has no actions (connect.py:163-166). Fix: one `connect-halt` form panel (target dropdown + confirm) both TUI Connect and web call.
17. minor §1 scope: coworker device on a company network can halt your folders; define "folders on that membership"; primary-network halt also stops folders on no network.
18. minor: while halted, web session create fails (spawned --detached refused at boot) and halted owner's web chats get no turns; say what the user sees.
19. minor service unit: launchd SuccessfulExit:false restarts once after SIGTERM/SIGKILL; units need reinstall on upgrade; cli.py:1612 "(it restarts …)" text becomes wrong.
20. minor: say whether a halt in force lifts when its issuer is revoked.
21. minor assumption 10: OAuth profile keys never sync (config_sync.py:1121-1124) and OpenAI Realtime needs a platform key, so synced llm profiles may give no usable key.

Verified correct by the reviewer: cli.py:1752/:1607 (stop is folder-scoped), service.py Restart=always/KeepAlive, config_sync.py:62/:73-74/:441/:1122, PARK_AFTER_SECONDS, voice engines + preferences.json, kollabor.voice.enabled, voice panel lines, /config has no permissions section, contacts never get config (config_sync_service.py:324-326).
