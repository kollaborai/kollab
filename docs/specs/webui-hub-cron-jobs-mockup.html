Schedules

A schedule sends one prompt to one or more agents on a timer.

How to get started

  1. 1Open Settings, then Schedules, and press Add schedule.
  2. 2Type the prompt, set Every to 30s, 5m, 1h or 2h30m, and switch on the agents under Runs in.
  3. 3Keep Enabled on and press Save schedule. For many at once, press Import file.

Try an example

Settings, Schedules, Generate with agent. Type: every 2 hours, ask lapis for a one-line status

Good to know: Today schedules are in memory and are lost when the agent stops. Planned: a file at ~/.kollab/schedules.json on this machine, and a schedule pauses while its device is off the network.
