- `/restart` restarts a detached agent in place on the installed Kollab version and keeps its conversation; `/new` and `/clear` clear it. A web chat whose agent runs an older version than the engine says so, with a Restart Agent button when `kollabor.updates.restart_agents` is on (default off) and the `/restart` line when it is off. Agents publish the version and build they run in presence, `GET /agents` and the network rows (#968).
