- The web UI's session panel has Code Editor, Git and Terminal views beside Chat and Trajectory, shown for a chat that
  has a folder. Code Editor is a Monaco editor with file tree, search, quick open and split panes; Git is its own view
  (status, stage, commit, branches, stash, log, diff) with the git panel beside the same editor panes, so diffs and files open next to it;
  Terminal is a real shell. The engine serves them from `/code/fs/*`,
  `/code/git` and a `/code/terminal` WebSocket, all held to the engine folder rule (#987).
