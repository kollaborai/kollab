- The web UI's session panel has a Code Editor and a Terminal button. Each opens a draggable floating window for the
  chat's folder: a Monaco code editor with file tree, search, quick open, split panes and a git panel (status, stage,
  commit, branches, stash, log, diff), and a terminal on a real shell. The engine serves them from `/code/fs/*`,
  `/code/git` and a `/code/terminal` WebSocket, all held to the engine folder rule (#987).
